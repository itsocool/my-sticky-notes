# Microsoft Sticky Notes 클론 구현 계획

승인된 계획: macOS 우선, 한국어 UI, 원본에 가까운 외형, 로컬·오프라인 저장,
텍스트 서식, 독립 노트 창, 메뉴 막대 상주, 노트별 상단 고정.

## 제품 동작

- 목록 기본 360×640, 최소 320×420. 검색과 최근 수정 순 카드 목록.
- 노트 기본 320×360, 최소 240×200. 새 노트·고정·더보기·닫기와 하단 서식 도구.
- 노랑·초록·분홍·보라·파랑·회색·짙은 회색. 새 노트는 노랑, 고정 꺼짐.
- 굵게·기울임·밑줄·취소선·글머리 목록과 실행 취소·다시 실행.
- 첫 번째 비어 있지 않은 줄을 목록 제목으로 사용. 빈 노트는 ‘새 메모’.
- 닫기는 숨김, 삭제는 확인 후 영구 삭제. 목록 창을 닫아도 앱은 유지.
- 메뉴 막대: 새 메모, 메모 목록, 종료. Dock 재실행도 목록을 표시.
- ⌘N 새 노트, 목록의 ⌘F 검색, 편집기 서식 단축키. 전역 단축키 제외.
- 시스템 밝은/어두운 테마. 키보드 포커스·접근성 이름·툴팁 제공.

## 구조와 인터페이스

- React + TypeScript + Tiptap 3. 목록과 편집기를 별도 컴포넌트로 분리.
- Rust + bundled rusqlite. 앱 데이터 디렉터리의 SQLite에 저장하며 schema version 관리.
- 노트: UUID, 문서 JSON, 검색용 일반 텍스트, 색상, 고정, 생성·수정 시간.
- 창: 노트 UUID, 논리 좌표·크기·열림 상태. 창 이동은 노트 수정 시간을 바꾸지 않음.
- 명령: list_notes, get_note, create_note, save_note, set_note_color, delete_note,
  open_note, close_note, set_note_pinned, show_notes, request_quit, acknowledge_quit.
- 저장 성공 후 notes:changed 이벤트. 구독 후 초기 목록 로드.
- 목록 main, 노트 note-{UUID}. 같은 노트는 하나의 창만 열고 기존 창을 포커스.
- 편집 후 500ms 자동 저장. 노트별 직렬화, 한글 조합 종료 후 저장.
- 닫기·종료 전에 대기 중인 저장 완료. 실패 시 초안 유지·오류·재시도, 종료 취소.
- 삭제 후 늦은 저장은 거부. DB 오류가 발생해도 기존 파일을 초기화하지 않음.
- 정상 종료 전에 열려 있던 창의 좌표·크기·고정을 다음 실행에 복원.
- 모니터 변경 시 화면 안으로 창 위치 보정. 단일 인스턴스 플러그인 적용.
- 필요한 창에만 권한을 부여. 외부 콘텐츠 로드 및 임의 파일 접근 없음.

## 작업 순서와 확인 기준

1. SQLite 저장 계층과 CRUD/삭제 후 저장 거부/재조회 테스트.
2. React 목록·검색·편집·서식·색상·저장 상태와 자동 저장 직렬화 테스트.
3. 창 관리·메뉴 막대·종료 전 저장·창 복원·중복 실행 방지.
4. 실제 macOS에서 한글, 여러 창, 입력 직후 닫기/종료, 복원, 고정 검증.
5. npm run check, npm test, cargo test, npm run build, npm run tauri build.
6. README와 AGENTS 갱신, docs/implementation-results.md에 결과·제한 기록.

## 기본값과 제외 범위

처음 실행은 빈 목록. 예제 데이터를 실제 저장하지 않음.
이미지·계정·동기화·자동 업데이트·Windows 검증·전역 단축키 제외.
강제 종료 또는 전원 차단 직전의 아직 저장되지 않은 입력은 복구 보장하지 않음.
기존 미커밋 개발 환경을 보존하고 승인된 계획대로 현재 저장소에서 작업.

## 실행 기록

- 실행 방식: 현재 세션에서 순차 구현, 마지막에 별도 코드 리뷰.
- Ruling: 이전 개발 환경이 미커밋 상태이므로 현재 작업 폴더를 유지하고 임의 커밋·worktree 이동을 하지 않는다.
- 브라우저 QA: Browser 플러그인이 제공되지 않으므로 Playwright를 사용한다. 네이티브 동작은 실제 Tauri 앱으로 검증한다.
- 저장 계층 RED: Store/WindowState 미구현을 확인했다. 최초 실행에서 남아 있던 opener 권한 오류를 제거한 뒤 저장 API 부재를 확인했다.
- 자동 저장 RED: Autosave 모듈이 없는 상태에서 테스트 실패를 확인했다.
- 시안: docs/design-concept.png. 플랫한 파스텔 카드, 12px 목록 여백, 36px 노트 헤더·툴바, 시스템 글꼴. 시안의 예제 내용은 QA에만 사용하며 최초 실행은 빈 목록이다.

- 저장 계층: 7개 Rust 테스트 통과. 자동 저장·목록·서식·종료 생명주기: 13개 프런트엔드 테스트 통과.
- 읽기 전용 최종 리뷰에서 Important 경로를 재현해 회귀 테스트로 수정했다. 숨긴 창 flush는 화면 프레임에 의존하지 않는다.
- Ruling: 본문 저장 확인 후 창 좌표 저장 실패는 종료를 막지 않는다. 좌표는 마지막 저장값으로 복원한다.
- 실제 앱 QA: 한글 저장, 색상, 고정, 숨김 후 종료, 열린 창 복원, 단일 인스턴스, 검증 노트 삭제 확인.
- 최종 검증 상세와 환경 제약은 implementation-results.md에 기록한다.
